A personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion. Features a modern responsive design, smooth animations, and a clean user experience.

## Features

- Modern responsive UI
- Dark & Light theme
- Interactive project showcase
- Skills and experience timeline
- Resume download
- Smooth animations
- Contact section
- Fast performance with Vite

## Tech Stack

| Technology | Purpose |
|---|---|
| React | Component-based UI |
| Vite | Build tool & dev server |
| Tailwind CSS | Utility-first styling |
| Framer Motion | Animations |
| React Icons | Icons |
| Space Grotesk | Heading font |
| Inter | Body font |

## Getting Started

```bash
git clone https://github.com/adityanarayan679/portfolio.git
cd portfolio
npm install
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## Deployment (Vercel)

1. Push the repository to GitHub.
2. Import it into Vercel.
3. Vercel detects Vite automatically.
4. Every push to `main` triggers a new deployment.
